Ramu Kaka.ai — A Voice-Activated AI Butler

Ramu Kaka.ai is a local, voice-activated personal assistant designed to run on a Windows laptop.
It uses offline wake-word detection, speech recognition, and text-to-speech to interact with users and perform everyday tasks through natural voice commands.

The project focuses on modular design, offline-first architecture, and extensibility, making it easy to add new features such as task management, timers, quizzes, and personalized information services.

✨ Features (Current & Planned)
✅ Implemented

  🎙️ Offline Wake Word Detection
    Custom wake word: “Ramu Kaka”
    Powered by Picovoice Porcupine

  🗣️ Speech-to-Text
    Converts spoken commands into text

  🔊 Text-to-Speech (Windows-safe)
    Uses pyttsx3 with a per-call engine strategy for stability

  🧩 Modular Project Structure
    Clean separation between core logic and features

🚧 Planned Features

  📝 To-Do List Management
  
  ⏱️ Timers & Reminders

  📰 Personalized News Updates
  
  🌦️ Weather Forecasts
